# Sathyanarayanan — AI/ML Engineer Portfolio

A responsive, minimal portfolio website built with HTML, CSS and vanilla JavaScript.

## Included
- `index.html` — page content and sections
- `style.css` — responsive styling
- `script.js` — mobile navigation and subtle reveal animations
- `assets/profile.png` — profile photograph supplied for this portfolio
- `assets/resume-placeholder.pdf` — temporary downloadable resume placeholder

## Run locally
Open `index.html` in a browser. For local development, you can also run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Replace the resume
Replace `assets/resume-placeholder.pdf` with your actual PDF and rename it to `resume.pdf`, then update the Download Resume link in `index.html` from:
`assets/resume-placeholder.pdf`
to:
`assets/resume.pdf`

## Contact
The contact section intentionally displays direct email, phone, LinkedIn and GitHub links. There is no contact form.

## Publish with GitHub Pages
1. Create a GitHub repository for the portfolio.
2. Upload the contents of this folder to the repository root.
3. In repository Settings → Pages, select the deployment branch and root folder.
4. Save and wait for GitHub Pages to publish the site.
